# 云服务器部署指南（华为云 + Docker 示例）

> 目标：把后端跑在一台**有公网 IP 的云服务器**上，让 Coze（扣子）等外部平台能稳定调用。
> 本文以华为云 Ubuntu 22.04 为例；其他云厂商（阿里云 / 腾讯云 / AWS）操作类似。

---

## 1. 购买服务器与放行端口

| 项目 | 建议值 |
| --- | --- |
| 系统 | Ubuntu 22.04（或 Debian 11） |
| 配置 | 2 核 / 3.5GB 内存起（模型加载 + 查询够用） |
| 磁盘 | 40GB 起（UMLS 数据库约 2.2GB + 镜像） |
| 安全组 | 入方向放行 **TCP 7680**（后端端口） |

**安全组放行**：云控制台 → 云服务器 → 安全组 → 入方向规则 → 添加：协议 TCP、端口 7680、来源 0.0.0.0/0（公网访问）。

> ⚠️ 上线后请尽快：① 修改 root 密码并改用 SSH 密钥登录；② 后端当前为演示用途、未加鉴权，公网公开前建议加简单 Token 校验（见文末）。

---

## 2. 安装 Docker

```bash
# 国内网络建议先配置 Docker 镜像加速（daocloud / 华为云加速器）
sudo apt-get update
sudo apt-get install -y docker.io
sudo systemctl enable --now docker
sudo usermod -aG docker $USER   # 重新登录后生效
```

---

## 3. 上传代码与数据到服务器

在本地准备好两份东西：

```bash
# ① 代码：上传整个仓库（含 Dockerfile.deploy、helper.py、en_Labels.js、
#    disease-symptom-merged.csv、data/、umls/ 等运行所需文件）
scp -r ./medical-diagnosis-assistant root@<服务器IP>:/root/app

# ② UMLS 数据库（约 2.2GB，单独上传，不随代码走）
scp ./umls.db root@<服务器IP>:/root/umls_data/umls.db
```

> 也可先打 tar 包再上传：`tar czf app.tar.gz medical-diagnosis-assistant` → 服务器上解压。

---

## 4. 构建镜像并启动

```bash
cd /root/app

# 构建（使用仓库内的部署专用 Dockerfile，依赖走华为云 PyPI 镜像）
docker build -f Dockerfile.deploy -t med-backend .

# 启动：挂载 UMLS 数据库目录到容器内 /umls/databases
docker run -d --name med-backend \
  -p 7680:7680 \
  -v /root/umls_data:/umls/databases \
  --restart unless-stopped \
  med-backend
```

`Dockerfile.deploy` 内容（也已在仓库根目录）：

```dockerfile
FROM python:3.6
COPY . /
RUN pip install --no-cache-dir -i https://mirrors.huaweicloud.com/repository/pypi/simple/ \
    "flask==1.0.2" "jsonschema==3.0.1" "numpy==1.16.2" "pandas==0.24.2" \
    "scipy==1.2.1" "scikit-learn==0.21.1" "requests==2.21.0" \
    "flask-expects-json==1.3.1" "Flask-Limiter==1.0.1" "more-itertools" \
    "Werkzeug==0.14.1" "future==0.17.1"
EXPOSE 7680
CMD ["python", "/app_1119.py"]
```

> 说明：容器内工作目录为 `/`，代码文件被 `COPY . /` 放到根目录；`umls.db` 通过 `-v` 挂载到 `/umls/databases/`，避免打进镜像（镜像保持轻量）。

## 5. 验证

```bash
# 服务器本机
curl -X POST "http://127.0.0.1:7680/api/validateSymptom?name=fever"
# 期望：{"C0015967":"fever"}

# 公网（任意电脑/手机，需已放行安全组）
curl -X POST "http://<服务器IP>:7680/api/validateSymptom?name=fever"

# 常用自检
docker ps                          # med-backend 处于 Up 状态
docker logs --tail 50 med-backend  # 查看启动日志（应出现 Running on http://0.0.0.0:7680/）
```

全链路自测：

```bash
curl -X POST "http://<服务器IP>:7680/api/predict?symptoms=C0015967,C0006425"
curl -X POST "http://<服务器IP>:7680/api/sySuggest?symptom=C0015967"
curl -X POST "http://<服务器IP>:7680/api/getDetails?code=C0015967"
```

## 6. 维护

| 操作 | 命令 |
| --- | --- |
| 重启容器 | `docker restart med-backend` |
| 查看日志 | `docker logs -f med-backend` |
| 更新代码 | 重新上传 → `docker build -f Dockerfile.deploy -t med-backend .` → `docker rm -f med-backend` → 重新 `docker run`（同上） |
| 开机自启 | 已通过 `--restart unless-stopped` 实现 |

## 7. （可选）给后端加简单鉴权再公开

演示阶段可不加；若 README 里要挂"在线 Demo"地址给陌生人访问，建议先加：

在 `app_1119.py` 顶部加一个请求钩子，要求请求头带 `X-API-Token`（示例，仅拦截非 `/` 路径）：

```python
API_TOKEN = "换成你自己的随机串"

@app.before_request
def check_token():
    if request.path.startswith('/api') and request.headers.get('X-API-Token') != API_TOKEN:
        return jsonify({"error": "unauthorized"}), 401
```

然后在 Coze HTTP 节点「请求头 Headers」里加一行 `X-API-Token: 你的随机串`，两端一起改即可。
